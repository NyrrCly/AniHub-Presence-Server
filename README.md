### How to use

Make sure Discord is running.

1. Download extension from [my another repository](https://github.com/NyrrCly/AniHub-Presence-Extension).
2. Add extension in FireFox browser.
3. Download server from [releases](https://github.com/NyrrCly/AniHub-Presence-Server/releases).
4. Run .exe file.

Just watch anime, and the activity will work!
